## ⚡ 30 秒速览

**不下载模型文件，不等于没有供应链风险。**

使用托管 API 时，重点从本地文件转向上游服务和集成配置：

| 风险 | 核心问题 |
| --- | --- |
| Silent model update | 地址不变，背后的模型行为变了 |
| API key compromise | 凭据泄露，被他人以你的身份使用 |
| Prompt template injection | 外部模板被修改，应用规则跟着变 |
| Upstream training data poisoning | 上游训练或微调数据影响模型判断 |

## 1. 为什么文件分析不够？

前面任务分析的是下载、加载和自行托管的模型。通过 API 使用模型时，你通常拿不到上游权重和训练流水线，不能用 `pickletools` 检查远端模型。

**检测重点改变了：** 版本、行为、调用身份、模板来源和业务影响。

API 响应与本地集成仍需按不可信数据处理，并非所有文件或传统应用风险都消失了。

## 2. Silent Model Updates：静默模型更新

**是什么？** API 地址保持不变，提供商更新、微调或替换背后的模型，消费者可能没有明确察觉。

### TryTrainMe 风险

代码审查助手仍调用同一地址，但对安全问题的分类发生变化，可能放行本应进一步审查的变更。

### 原文防御建议

- 在支持的情况下固定部署或模型版本。
- 记录响应中可获得的模型版本标识。
- 用固定测试集建立行为基线。
- 对异常输出漂移告警。

**注意：** 普通模型标识不一定是不可变快照；固定别名也未必保证行为永远相同。应按服务实际承诺判断。

## 3. API Key Compromise：密钥泄露

**是什么？** API 密钥作为凭据，从源码、CI/CD 日志或环境文件等渠道泄露。

### 可能后果

- 在密钥权限范围内调用 API。
- 消耗配额或增加费用。
- 访问该凭据实际有权读取的资源。

原文还称密钥泄露会暴露所有历史代码审查请求，并且不留下取证痕迹。**这不能自动成立：**

- 只有密钥，不等于必然有权限读取全部历史请求。
- 日志泄露了哪些请求，要看日志实际内容。
- 本地、CI/CD 和提供商审计日志仍可能留下证据。

### 原文防御建议

使用秘密管理、避免写入源码或日志、怀疑暴露时轮换，并设置可用的费用告警和速率限制。

**补充理解：** 环境变量不是独立的安全边界，其风险取决于谁能读取进程、配置和运行日志。

## 4. Prompt Template Injection：提示模板注入

**是什么？** 应用从共享仓库或模板库取得系统提示。如果上游模板被篡改，加载它的应用也可能改变行为。

### TryTrainMe 风险

代码审查模板来自社区库，部署后未再审查。恶意修改可能要求 TryAssist 无条件批准 PR。

### 原文防御建议

- 将系统提示词当作代码管理。
- 在自有仓库中版本控制。
- 审查外部变更后再发布。
- 不自动信任远程模板的最新内容。

**记忆点：供应链产物可以是一段文字，不一定是模型文件。**

## 5. Upstream Training Data Poisoning：上游训练数据投毒

**是什么？** 你看不到提供商的完整训练过程，但被污染的训练或微调数据可能导致系统性异常输出。

### TryTrainMe 风险

原文举例：模型在含恶意安全公告的数据上微调，导致持续低估 SQL 注入严重度。

### 原文防御建议

- 定期用已知风险样本评估输出。
- 对高影响决定保留人工审查。
- 将行为可靠性当作需要持续管理的风险。

**证据边界：** 输出偏差可以通过测试观察，但单凭偏差不能证明具体训练数据曾被投毒。日志与输出仍有调查价值，不应理解为任何异常都不可发现。

## 📌 6. 四类风险对照

| 观察到的问题 | 优先检查 |
| --- | --- |
| 同样测试集表现改变 | 版本标识、发布记录、配置与行为漂移 |
| 调用量或费用异常 | 密钥使用身份、来源、配额与审计 |
| 审查流程突然不执行 | 模板版本、内容差异与加载来源 |
| 固定类别被持续低估 | 评估集、人工复核与上游变更信息 |

## ✍️ 7. 题目与答案

### Q1：API 背后模型在消费者不知情时被替换，叫什么？

```text
Silent model update
```

**为什么？** 端点没变，但其背后模型发生变化，题目询问的是这种更新风险。

### Q2：从不可信仓库取得、能改变所有使用它的应用行为的产物是什么？

```text
Prompt template
```

**为什么？** 模板决定应用传给模型的指令，也是需要来源验证与变更审查的供应链产物。
