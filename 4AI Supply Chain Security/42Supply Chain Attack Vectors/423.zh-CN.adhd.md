## 3. 第二步：使用 pickletools 静态检查

课程输出的关键片段：

## 4. 第三步：识别危险组合

### 关键不是单个词，而是调用链

| 特征 | 含义 |
| --- | --- |
| `os` + `system` | 指向系统命令执行函数 |
| `STACK_GLOBAL` | 解析栈上的模块与名称，取得对象引用 |
| curl 字符串 | 计划进行外部 HTTP 请求 |
| `TUPLE1` | 将参数组织成单元素元组 |
| `REDUCE` | 按重建逻辑调用函数并传入参数 |

**更准确的区别：** `STACK_GLOBAL` 本身不等于已经执行命令；这里真正需要警惕的是它解析出 `os.system`，随后由 `REDUCE` 配合命令参数形成调用。

原文各表中的行号与示例偏移存在小差异，分析时以实际输出和指令名称为准。

### 优先调查的字符串

```text
os
system
popen
subprocess
socket
eval
exec
curl
wget
```

这些能力与纯权重恢复通常不相称，值得调查，但**文本命中本身不是充分结论**；还需确认是否真的被引用、调用以及参数用途。

`STACK_GLOBAL` 与 `REDUCE` 在合法 pickle 中也很常见，不能仅凭出现就认定恶意。
