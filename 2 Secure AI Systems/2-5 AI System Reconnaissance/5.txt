### **Task 3: Fingerprinting AI Services**

This task taught how to identify AI frameworks via HTTP headers, JSON response structures, error messages, and gRPC reflection — rather than relying on Nmap banners alone.

Steps included:
- `curl http://10.10.45.15:8000/v2/models` → looks for `platform` field and the `NV-Status` header
- `grpcurl -plaintext 10.10.45.15:8001 list` → gRPC reflection reveals service name
- Sending malformed requests to trigger framework-specific error messages

**Q1:** Which unique HTTP response header does the service on 10.10.45.15:8000 return to identify as an NVIDIA product?
**A:** `NV-Status` ✅

**Q2:** When you run `grpcurl` against 10.10.45.15:8001, what is the name of the inference service listed in the reflection output?
**A:** `inference.GRPCInferenceService` ✅

**Q2:** What is the single most effective quick win for preventing unauthenticated access to the MLflow tracking server?
**A:** `Enable MLflow authentication` ✅
